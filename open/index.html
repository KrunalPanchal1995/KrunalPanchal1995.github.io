Open science

Open science

The code and notes behind these plots can be shared. Nothing here costs money. Some files are open now, the rest are sent by email once I approve a request.

Free of cost

Downloads and requests are free. There is no payment, no account and no subscription. The request step exists only so that a file reaches the person who wants it.

Open now

The code and PDF notes for the home page fluid demo can be downloaded straight away.

Shared on approval

For every other plot I review the request and reply by email with the code and the PDF notes. The request goes to me, and nobody else sees it.

What is shared

  • The plot's code (Python or Julia), as a zip.
  • The PDF notes that explain the plot.

What is never shared

  • Anything from work that is not yet published (see the disclosure policy).
  • Private data and credentials.

To recreate a plot

  1. Watch the clip in the Studio.
  2. Request the code and PDF notes for that plot.
  3. Run the code and change the inputs.

How the Studio fits in

The Math Studio is a teaching and showcase tool. It plays short clips of how a plot is built and explains each figure. Math Studio
