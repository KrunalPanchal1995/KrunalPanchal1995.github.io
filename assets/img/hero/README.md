# Hero images

`placeholder_flow.jpg` (1920x1080) is a generated PLACEHOLDER: a Karman-vortex-street-like
scalar field in the teal/amber palette on graphite, with a small
"placeholder: replace with your image" label in the bottom-right corner.
It is also the WebGL-unavailable fallback for the `card3d` hero.

The site owner will supply the real image (a render or photograph of a flame / flow field).
To use it: drop the file here (e.g. `hero_main.jpg`, ideally 1920x1080, under ~400 KB,
dark enough that white text stays readable under the overlay) and set
`hero_params.photo.image` in `_data/design.yml`.
