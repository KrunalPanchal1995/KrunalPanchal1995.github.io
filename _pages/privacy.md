This site counts page views so I can improve it. For each view it records the page, the website you came from (just the hostname, such as `linkedin.com`), an optional tag from the link I shared, and your approximate location (country, region and city) as worked out by the server from your connection.

It does **not** store your IP address, browser details, cookies or any identifier, and it does not follow you between visits. To opt out, run `localStorage.setItem("ofsIgnore","1")` in your browser console. The code is open: [openfirststep](https://github.com/KrunalPanchal1995/openfirststep).
